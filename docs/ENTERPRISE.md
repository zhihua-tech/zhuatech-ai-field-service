# AI现场服务调度系统企业能力

## 领域覆盖

- **服务请求**：受理设备故障、客户影响、位置和服务承诺
- **工单中心**：生成优先级、任务步骤、责任和 SLA
- **技能与认证**：维护技师技能、资质、班次和服务区域
- **AI智能派工**：综合技能、距离、负载、备件和客户时间窗派工
- **路线优化**：生成多工单路线并处理交通和紧急插单
- **服务备件**：检查库存、车载库、替代件和紧急配送
- **作业安全**：校验许可、风险分析、隔离和个人防护
- **移动执行**：支持离线工单、扫码、照片、签名和工时
- **一次修复与复盘**：跟踪一次修复率、返工、满意度和模型偏差

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对AI现场服务调度系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `FSM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
